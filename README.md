### Task 3: Iris Flower Classification  
I worked on the classic Iris flower classification task, aiming to classify iris flowers into three species (setosa, versicolor, and virginica) based on sepal and petal measurements. Using supervised learning algorithms like logistic regression and decision trees, I built a model that accurately distinguishes between the species. This project provided a solid foundation in classification techniques and model evaluation.  
**GitHub Repository:** [Task 3 - Iris Flower Classification](https://github.com/kgsflink/CodeSoft_internship/IRIS_Flower_Classification_task3)
